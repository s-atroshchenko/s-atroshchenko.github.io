# Сайт-витрина услуг

Простые HTML и CSS, без сборки. Пути относительные, работает в корне и в подпапке.

## Файлы

- `index.html` главная
- `services/zayavki-i-prodazhi.html` страница услуги, она же шаблон
- `css/base.css` цвета, градиент, кнопки, шапка
- `css/pages.css` стили блоков главной и страницы услуги
- `favicon.svg` иконка вкладки

## Как добавить услугу

1. Скопировать `services/zayavki-i-prodazhi.html` в `services/novaya-usluga.html`.
2. Поменять `title`, `description`, заголовок и тексты в пяти блоках.
3. В `index.html` скопировать карточку в блоке `.cards`, поменять `href` и текст.

## Что осталось черновиком

- Все тексты услуг и шагов «Как я работаю» (помечены комментариями в HTML).
- Три варианта заголовка первого экрана лежат комментарием в `index.html`.
- Карточки «Сайты» и «Боты и ИИ-ассистенты» пока ведут в Telegram. После одобрения шаблона заменить на страницы услуг.

## Выкладка на GitHub Pages

1. Создать репозиторий, залить все файлы папки (кроме `.DS_Store`, `tz_*.txt`, `about.txt`, `gradient.jpg`, если не нужны в публичном виде).
2. Settings, Pages, Source: ветка `main`, папка `/ (root)`.
3. Через минуту-две сайт откроется по адресу `https://<имя>.github.io/<репозиторий>/`.
