# Сайт-витрина услуг

Простые HTML и CSS, без сборки. Немного JavaScript только для строки ввода на телефоне. Пути относительные, работает в корне и в подпапке.

Стиль «Переписка»: страница устроена как чат. Вопрос клиента слева серым пузырём, ответ справа.

## Файлы

- `index.html` главная
- `services/zayavki-i-prodazhi.html` страница услуги, она же шаблон
- `css/base.css` переменные (цвета, шрифты), подключение шрифтов, кнопки, шапка, подвал
- `css/pages.css` стили блоков главной и страницы услуги
- `js/float-button.js` строка ввода внизу экрана на телефоне (прячется на первом экране и в блоке контактов)
- `fonts/` шрифты Unbounded 600 и Golos Text 400-600 (файлы `woff2`, лицензия OFL). С чужих сайтов шрифты не грузятся
- `favicon.svg` иконка вкладки

## Цвета и шрифты

## Три вида блоков

1. **Сообщение клиента** `.q`: серый пузырь слева. Это вопрос и заголовок блока (`h2`).
2. **Ответ** `.a`: пузырь справа. Три вида:
   - `.a--accent` зелёный: только первый экран и контакты;
   - `.a--calm` светло-зелёный: цены, шаги, условия, ответы на вопросы;
   - `.a--dark` тёмный: уведомление менеджеру.
3. **Строка ввода** `.composer`: только на телефоне, внизу экрана.

Кнопки: `.btn` плюс вариант `.btn--yellow`, `.btn--green`, `.btn--line-white`, `.btn--line-ink`. Маленькая: `.btn--small`.

## Из чего состоит главная

1. Шапка: «Сергей», меню, кнопка Telegram (на телефоне меню скрыто)
2. Первый экран: вопрос клиента, главный ответ с заголовком, ценой «от» и двумя кнопками
3. «Сколько это стоит?» (`#uslugi`): прайс из 4 строк и строка «Другая задача» с кнопкой
4. «А как это будет выглядеть у менеджера?» (`#kak-eto-vyglyadit`): три шага и тёмное уведомление
5. «Как идёт работа?» (`#kak-idet-rabota`): 5 шагов
6. «А на каких условиях?» (`#usloviya`): 4 условия
7. «Ещё вопросы» (`#voprosy`): 9 вопросов на `<details>`, по умолчанию свёрнуты
8. Контакты (`#kontakty`): главный ответ с двумя кнопками
9. Подвал и строка ввода на телефоне

Блок «Примеры работ» пока убран (см. ниже, как вернуть).

В меню нет блоков про менеджера и условия: они доступны только прокруткой.

## Как добавить услугу

1. Скопировать `services/zayavki-i-prodazhi.html` в `services/novaya-usluga.html`.
2. Поменять `title`, `description`, теги `og:` и тексты блоков.
3. В `index.html` в блоке `#uslugi` скопировать строку `<div class="price-row">`, поменять название, цену и тексты. Если у услуги есть своя страница, добавить в конец абзаца ссылку «Подробнее».

## Как добавить вопрос в «Ещё вопросы»

В `index.html` в блоке `<div class="faq">` скопировать целиком `<details>...</details>`, поменять вопрос в `<summary>` и ответ в `<div class="a a--calm">`.

## Версии файлов (важно)

К ссылкам на CSS и JS в обеих страницах приписано `?v=7`. **При любой правке CSS или JS номер увеличивать** (`?v=8` и так далее) в обоих HTML, иначе телефоны показывают старые стили из кэша.

## Как вернуть блок «Примеры работ»

Когда появится второй пример, добавить блок между «Что видит менеджер» и «Как идёт работа»: вопрос клиента (`h2.q`, например «А что вы уже делали?») и ответ `.a.a--calm` с примерами, плюс пункт `<a href="#primery">Примеры</a>` в меню обеих страниц.

Блок «Примеры работ» в стиле «Переписка» нужно будет оформить заново: старых классов `.cards` и `.tag` в CSS больше нет. Заглушки «скоро» не добавляем.

## Метки для Яндекс Метрики

У каждой кнопки и ссылки на Telegram или почту есть класс `js-contact` и атрибут `data-place` (место кнопки: `header`, `hero`, `hero-mail`, `card-other`, `faq-mail`, `contacts`, `contacts-mail`, `footer`, `footer-mail`, `float` для строки ввода). На странице услуги к ним добавлена приставка `service-`. Метки `card-site`, `card-bot`, `card-ai` больше не используются: у этих строк прайса нет отдельных ссылок. Счётчик Метрики пока не подключён: цели настроим позже по этим меткам.

## Что осталось черновиком

- Все тексты: цены, условия, ответы в «Частых вопросах», блок «Что понадобится от вас» на странице услуги. Их утверждает Сергей.
- Макет уведомления («Анна», «14:32»): пример, не точный вид будущего уведомления.
- Для строк «Сайт», «Бот в Telegram или MAX», «ИИ-ассистент» страниц услуг пока нет. Связь через кнопку в шапке и строку ввода. Строка «Другая задача» ведёт в Telegram.
- Вопросы клиента на странице услуги написаны без Сергея, ждут его одобрения.
- Нет `robots.txt` и `sitemap.xml`, нет картинки для превью ссылки.

## Выкладка на GitHub Pages

1. Создать репозиторий, залить все файлы папки (кроме `.DS_Store`, `tz_*`, `about.txt`, `gradient.jpg`, если не нужны в публичном виде. Папка `fonts/` нужна обязательно).
2. Settings, Pages, Source: ветка `main`, папка `/ (root)`.
3. Через минуту-две сайт откроется по адресу `https://<имя>.github.io/<репозиторий>/`.
